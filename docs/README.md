# docs：逆向分析档案

这个目录保存「位置模拟器」原软件（com.yangtools.gps.simulator 2.9.12）的逆向分析产物，是本复刻工程的行为依据。

- `analysis/README-逆向过程.md`：工具安装（leanrea / REA / jadx）与逆向过程记录；
- `analysis/spec/01-模拟定位实现机制.md`：原软件如何注入模拟定位（含证据行号、已见/推断标注）；
- `analysis/spec/02-开源复刻方案.md`：功能对齐表、模块划分、差异说明、验收标准；
- `analysis/00` 到 `11`：逐屏交互、坐标系、地图搜索、定位行为、通知、数据模型、自检、订阅、异常边界、证据索引。

> 安全说明：反向工程过程中在原软件资源里读到的第三方 API key（百度地图 SDK key、百度 Place web AK、Google Maps key、
> Google API key）**已在全部分析文档中脱敏为 `<REDACTED-...>` 占位符**，本仓库不转储任何真实密钥。这些密钥原本内嵌在公开可下载的
> APK 里，但其所有权属于原软件开发者；如需使用相关服务，请自行申请自己的 key。
>
> 这些文档里的证据路径（`sources/...:行号`）相对于反编译产物 `re-tools/jadx-out/`；该目录体积大且属于原软件的反编译结果，不随本仓库分发。要复核某条结论，可用 jadx 重新反编译原始 APK 后按行号查找。
