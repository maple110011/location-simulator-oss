## 3. 自检对启动的拦截（已见）
- `MainActivity.h0(L3.a callback)`（`MainActivity.java:1453-1459`）：
  ```
  if (pref_self_check_completed == true && P().b()) callback.run();
  else P().f(new G(this, callback));     // 弹自检对话框，Continue 后回调
  ```
- Continue 回调 `F0/G.java:33-37`：写 `pref_self_check_completed=true`，再执行真正的启动动作。
- 因此：**首次启动模拟必然经过自检对话框**；通过一次后，只要 required 项仍全部满足，后续直接启动（不再弹框）。任何一项失效（例如关了开发者选项）会重新弹框。
- `h0` 的三个调用点：
  1. btnStart（LOCATION 模式）→ `MainActivity.java:2113`；
  2. 收藏/历史 Quick start → `MainActivity.z` :508；
  3. 路线启动 → `w0()` :4479（点数为 2 才走到这里）。
- 设置页 "Run check" 直接调 `P().f(null)`（无回调，只检测）（`J0/u.java:103-113`）。
