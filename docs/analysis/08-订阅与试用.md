## 4. 试用（Free Trial）机制（已见）
### 4.1 配置来源
Firebase Remote Config（读通过 `R()` = `T2.b` RemoteConfig 实例，`F0/C0082b.java:34-40`）：
- `trial_enabled`（默认 true）
- `trial_duration_hours`（默认 72，运行时钳到 ≥72）
- 读取与钳制：`MainActivity.C()`（`MainActivity.java:778-796`）→ 换算 `f9446K0 = hours*3600*1000`（:795）。
- 远程配置拉取：`MainActivity` onCreate 里注册 remote config 拉取回调 `F0/C0087g@case4`（失败只打日志），拉取完成后 `C()` 刷新参数（`F0/C0087g.java:84-89, 104-112`）。

### 4.2 试用判定算法（`MainActivity.E()` + `F0/C0101v` + `F0/C0103x`）
```
E(showLoading, callback):
  if (!trial_enabled) → callback(false)                      // 试用关闭 = 无试用
  if (showLoading) q0()                                      // 显示转圈
  androidId = Settings.Secure.getString(cr,"android_id") 去空白
  if (androidId 为空) → callback(false)                      // (日志: allow trial 但实际返回 false)
  doc = firestore.collection("devices").document(androidId)

  // 1) 先读缓存快照（source=CACHE）
  若缓存 doc 存在:
       firstSeen = doc.firstSeenAt ; lastSeen = doc.lastSeenAt
       若 firstSeen 存在:
           elapsed = max(lastSeen, now) - firstSeen
           isActive = (elapsed <= trialMs) || (elapsed < 0)
           callback(isActive) 并返回
       否则 → 走服务器流程 L()
  否则 → L()

  // 2) 服务器流程
  若 doc 存在:
       若 firstSeenAt 为空 → x(): 创建文档 {firstSeenAt=serverTimestamp, lastSeenAt=serverTimestamp}
                             → Toast "Free trial started."（trial_started）→ callback(true)
       否则 → 更新 {lastSeenAt=serverTimestamp}，再读一次 → 计算
              elapsed = lastSeen - firstSeen ; isActive = elapsed <= trialMs || elapsed < 0
              callback(isActive)
  否则 → x(): 创建文档 → callback(true)

  任何 Firestore 错误 → callback(false)（F0/C0091k:24-44）
```
- 证据：`MainActivity.java:841-869`、`F0/C0101v.java:31-87`、`F0/C0103x.java:29-56`、`F0/C0091k.java:21-45`、`MainActivity.java:451-458`（创建文档）。
- 语义（**推断 & 已见混合**）：试用是"按设备（Android ID）在云端记时"，从第一次创建记录（firstSeenAt）开始计时，每次查试用都会刷新 lastSeenAt；即使用户卸载重装，只要 Android ID 不变且文档仍在，试用不会重置。本地没有任何试用缓存（除内存 P0）。
- 边界：时钟回拨（elapsed<0）判为"仍有效"（`F0/C0103x.java:49`、`F0/C0101v.java:46`）。

## 5. 拦截点汇总（复刻时必须在这些地方闸门）
1. **点 Start（单点）**：自检之后、真正发 START_MOCK 之前（F0/G.a）。
2. **点 Start（路线）**：自检之后、真正发 START_ROUTE 之前（F0/A case 10）。
3. **库内历史/收藏的 Quick start**：走 `MainActivity.z` → h0 → 同一个闸门（:504-509）。
4. **debuggable 包直接放行**：`(ApplicationInfo.flags & 2) != 0` 时完全跳过订阅与试用（`F0/G.java:42`、`F0/A.java:90`）。
5. 订阅成功后自动继续刚才被拦下的启动（`MainActivity.java:1237-1247`，用 a1 路线或 E0 单点）。
