## 3. 运行期错误上报到 UI（已见）
- Service `j(Throwable)`（`MockLocationService.java:359-378`）：
  1. `Log.e("MockLocationService","Mock location failed", th)`
  2. 移除 tick 回调
  3. 状态 = 旧状态.copy(isRunning=false, errorMessage=th.message 或异常类名)
  4. 回调 `F0.K.b(state)`；清理 provider；释放 WakeLock；stopForeground + stopSelf
- MainActivity 侧 `F0/K.b()`（`F0/K.java:75-90`）：
  - 若 errorMessage 非空且与上次不同（字段 f9478b1 去重）→ `p0(@string/mock_location_failed "Mock location failed: %s")`（Toast，string :199）。**去重意味着不会每秒刷屏**。
  - 同时同步运行标志、模式、路线点、当前点、按钮状态（y0/A0）与坐标输入页按钮文案（r.k()）。

## 6. 进程重启 / Activity 重建（已见）
- Service 的返回值策略（`MockLocationService.java:541-544`）：运行中 `START_REDELIVER_INTENT(3)`，否则 `START_NOT_STICKY(2)`。
  - 推断：进程被杀时系统可能重建服务并重投最后一次 START_MOCK/START_ROUTE Intent（因为返回 3）；但服务实例字段（状态、路线点、traveled）会全部重置，重投 START_MOCK 可恢复单点模拟；START_ROUTE 依赖 Intent 里的 double[]，也可恢复路线。这是"能自愈"的设计（**推断**，未在代码中直接注释）。
- 无 Intent 重建（`onStartCommand(null, ...)`）：仅当 `state.isRunning` 为 true 时再 `g()` 一次（:535-540）——即同一进程内 Activity 重入场景。
- Activity 重建（旋转/低内存）：
  - `onSaveInstanceState` 保存路线点经纬度数组、速度、循环（`MainActivity.java:4253-4275`），`onCreate` 恢复（:1834-1853）。
  - 不保存：选中点 f9440H、运行标志、订阅/试用结果、地图实现实例。恢复方式：`M()`（`F0/M.java:42-62`）从 Room 取最近一条 HISTORY 恢复选中点；订阅/试用在 onResume 重新查询。
  - 地图相机状态由各实现 `e(Bundle)` 保存（百度空实现 `K0/d.java:172-175`；谷歌通过 Bundle 透传，`K0/h.java:315-345`）。

## 7. 返回键与导航边界（已见，`MainActivity.onBackPressed` :1743-1787）
1. 搜索态 → 退出搜索（`K()`）。
2. 抽屉打开 → 关闭抽屉。
3. 在地图页 → 两次返回退出：距上次 ≤2000 ms 才 `super.onBackPressed()`，否则 Toast @string/press_back_again_to_exit "Press back again to exit"（strings:298）。
4. 在其他 Fragment 页 → 回到地图页并把标题恢复为 title_location_simulator。

## 8. 其他边界（已见）
- 速度输入：空串或非法 → 用默认值 5.0 km/h（`b0()`，:1312-1318）；>300 或 ≤0 → 输入框报错不关闭对话框（:2189-2193）。
- 坐标输入越界：纬度/经度分别提示（`J0/r.java:211-237`）；非数字提示 "Please enter valid numbers"。
- 搜索双击/连续提交：用自增序号丢弃过期响应（`MainActivity.f9430A0`，:927-983；`F0/C0104y.java:330-334`）。
- 路线点重复（同坐标）会在几何计算中被 0.01m 阈值跳过（`p092v1/c.java:464`）。
- 收藏判重容差 1e-6 度（`I0/h.java:46`）。
- 远程配置失败：仅日志，沿用默认值（`F0/C0087g.java:104-112`）。
- Firestore 试用读取失败：回调 false（视为无试用）→ 用户被引导订阅（`F0/C0091k.java:24-44`）。
- Billing 不可用/取消：Toast subscription_unavailable；用户取消(code=1)时清掉待启动请求（`F0/C0087g.java:148-163`）。
- 地图 SDK 初始化：`SDKInitializer.setAgreePrivacy(true); SDKInitializer.initialize(...)` 在 setContentView 之前调用（`MainActivity.java:1819-1820`）。若 key 无效，代码没有显式降级逻辑（**推断**：地图空白，但模拟功能仍可用，因为模拟不依赖地图 SDK）。
- 空态：历史"没有历史记录"、收藏"没有收藏"、已存路线"没有已存路线"、广播无匹配结果（见各布局与 strings）。
