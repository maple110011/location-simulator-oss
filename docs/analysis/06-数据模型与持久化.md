```sql
CREATE TABLE IF NOT EXISTS records (
  id        INTEGER PRIMARY KEY AUTOINCREMENT NOT NULL,
  name      TEXT,                -- 可空

  longitude REAL NOT NULL,

```

### 1.2 saved_routes 表（`D2/I.java:319`）
```sql
CREATE TABLE IF NOT EXISTS saved_routes (
  id         INTEGER PRIMARY KEY AUTOINCREMENT NOT NULL,
  name       TEXT NOT NULL,
  speedKmh   REAL NOT NULL,
  loop       INTEGER NOT NULL,   -- 0/1
  points     TEXT NOT NULL,      -- "lat,lng;lat,lng;..."（分号分隔）
  updatedAt  INTEGER NOT NULL
)
```
- 实体 `I0.j`：SavedRoute(id, name, speedKmh, loop, points, updatedAt)（`sources/I0/j.java:6-35, 68-70`）。
- 写入 SQL：`INSERT OR REPLACE INTO saved_routes (id,name,speedKmh,loop,points,updatedAt) VALUES (nullif(?,0),?,?,?,?,?)`（`I0/k.java:4-28`）。
- 读取 SQL：`SELECT * FROM saved_routes ORDER BY updatedAt DESC`（`F0/P.java:41`）。
- points 的序列化：把 LatLng 列表 `join(";"){ "$lat,$lng" }`；反序列化用 `MainActivity.G(String)`：按 ';' 切、再按 ',' 切，必须恰好 2 段且能解析、纬度∈[-90,90]、经度∈[-180,180] 才收录（`MainActivity.java:410-435`；写入见 `F0/I.java:59`）。

### 2.1 使用习惯（已见）
- 历史页：HISTORY 最近 **50** 条 + FAVORITE 最近 **50** 条（`J0/i.java:120-136`）；列表只显示 HISTORY，FAVORITE 用于星标状态集合。
- App 恢复位置：启动/回到前台时取 HISTORY 最近 **1** 条恢复选中点（`F0/M.java:42-62`）。
- 每次启动单点模拟前写一条 HISTORY（`F0/T.java:63`）。
- 收藏判重用 1e-6 容差（约 0.1 m 量级）。

## 6. 保存的状态（已见）
- `onSaveInstanceState`（`MainActivity.java:4253-4275`）保存：state_route_latitudes、state_route_longitudes、state_route_speed、state_route_loop；同时让当前地图实现 e(bundle) 保存地图状态。
- `onCreate`（:1834-1853）恢复上述四个键，重建路线点列表。
- 注意：**不保存**当前选中点、模拟运行状态、试用/订阅结果；进程被杀后这些都要重新获取（见 09 号文档）。
