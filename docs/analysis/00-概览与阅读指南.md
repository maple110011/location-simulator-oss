产物为 `analyst/` 目录下的多个 markdown 文件，本文件是索引与全局说明。

其余 `sources/` 内容均为第三方/混淆库（百度地图 SDK、GMS、Firebase、Play Billing、Room、Material、Kotlin 协程）。**但有一类重要例外**：jadx 把 App 自己的部分工具/回调类合并进了混淆包名，散布在 `F0/`、`J0/`、`K0/`、`L0/`、`I0/`、`G0/`、`Q1/`、`A1/`、`p092v1/`、`p111z3/`、`D2/` 中。例如坐标换算工具被合并进了 `com/google/android/gms/internal/play_billing/AbstractC0323z0.java`（见 02 号文档）。判断依据：这些类里出现 App 的 R 资源、MainActivity、Record、MockLocationService 等自有符号。

## 6. 一句话业务概述（已见汇总）
这是一个"开发者/测试用模拟定位器"：用户在地图上选点或用坐标输入，App 通过 Android 测试 provider（gps/network，并在 GMS 可用时额外走 fused mock）持续注入指定坐标，可选"沿一条由若干点连成的折线以固定速度移动"，前台服务 + 通知栏提供暂停/停止，历史/收藏/已存路线持久化在 Room，首次使用有 6 项系统设置自检，启动模拟前有"订阅或试用"闸门，试用时长与开关由 Firebase Remote Config 控制。
