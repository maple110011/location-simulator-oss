# 05 通知栏行为

## 1. 通知渠道（已见）
- 渠道 id 字符串常量：**"MockLocationServiceChannel"**（`sources/A0/a.java:9-11` 创建 `new NotificationChannel("MockLocationServiceChannel", name, 2)`；`MockLocationService.java:266` 用同一字符串构造 Builder）。
- 创建时机：`MockLocationService.onCreate()`，且仅 SDK ≥ 26（`MockLocationService.java:419-432`）：
  ```
  channel.name        = @string/mock_service_channel_name        "Mock Location Service"      (strings.xml:202)
  channel.description = @string/mock_service_channel_description"Provides continuous mock location in background" (strings.xml:201)
  setShowBadge(false)
  setSound(null, null)          // 静音
  enableVibration(false)        // 不振动
  ```
- 重要性 = 2（IMPORTANCE_LOW，低优先级、无声音）——见 `A0/a.java:11` 的第三个构造参数。

## 2. 通知标识与前台服务（已见）
- 通知 id 固定 **1001**（`MockLocationService.java:201,296,299,410`）。
- 前台服务启动：
  ```
  g(): type = SDK>=29 ? 8 : 0     // 8 = FOREGROUND_SERVICE_TYPE_LOCATION
      SDK>=34: ServiceCompat.startForeground(this,1001,notification,8)   // D.a
      SDK>=29: ServiceCompat.startForeground(this,1001,notification,8)   // C.a
      否则:    startForeground(1001, notification)
  ```
  （`MockLocationService.java:290-301`；manifest 中已声明 `foregroundServiceType="location"`，AndroidManifest.xml:75）
- 启动顺序：START_MOCK/START_ROUTE 一进入就调用 `g()`，保证 5 秒内进入前台（:459,491,538）。

## 3. 通知内容（已见，`MockLocationService.e()` :235-284）
- 点击通知：打开 MainActivity，Intent flags=603979776（= FLAG_ACTIVITY_SINGLE_TOP | FLAG_ACTIVITY_CLEAR_TOP），PendingIntent flags=201326592（FLAG_UPDATE_CURRENT | FLAG_IMMUTABLE）（:238-240）。
- 标题：
  - 路线模式：@string/route_running_title "Route simulation is running"（strings.xml:330）
  - 单点模式：@string/mock_running_title "Mock location is running"（:200）
- 正文：
  - 基础串 = 坐标 "%.6f, %.6f"（:249）。
  - 路线模式：@string/route_notification_status "%1$.1f km/h · %2$s"（:252；速度 = state.speed * 3.6 换算成 km/h）。
  - 单点模式：若 START_MOCK 带了 location_name，正文 = "<name> · <坐标>"（用字符串拼接 " · "，:254-258）；没有名字则只显示坐标。
  - 位置未知（state.currentLocation==null）：@string/fetching_location "Fetching location..."（:260-263）。
- 小图标：`android.R.drawable.ic_menu_mylocation`（:270）。
- 通知 flags：`oVar.c(2)` → FLAG_ONGOING_EVENT；`oVar.c(8)` → FLAG_NO_CLEAR（`C/o.java:310-313` 的 `notification.flags |= i`）。即不可滑动清除的常驻通知。
- 每 1 秒 tick 结束时 `notify(1001, e())` 刷新一次（`A1/o.java:296`；`MockLocationService.java:201`）。

## 4. 动作按钮（已见，:241-242, 276-280）
| 顺序 | 图标 | 文案 | PendingIntent 目标 |
|---|---|---|---|
| 条件出现 | ic_media_pause | 路线模式且未完成时：`state.isPaused ? "Resume route" : "Pause route"`（strings.xml:282,286 notification_pause_route / notification_resume_route） | getService(requestCode=1, action="TOGGLE_ROUTE_PAUSE") |
| 总是 | ic_menu_close_clear_cancel | @string/stop_mock "Stop Mock"（strings.xml:410） | getService(requestCode=0, action="STOP_MOCK") |
- 暂停按钮仅在 `mode==ROUTE && !routeCompleted` 时加入动作列表（:277-279）。
- 两个 PendingIntent 的 requestCode 分别是 1 与 0，flags 均为 201326592（UPDATE_CURRENT|IMMUTABLE）。

## 5. 进度展示（已见）
- 通知正文里带速度与坐标；**没有系统 ProgressBar**（Builder 未调用 `setProgress`）。
- 进度百分比的权威展示在 App 内：route_panel 的 route_status 文本（`MainActivity.A0`，见 04 号文档第 7 节）和暂停文案。
- 结论：通知栏的"进度显示"= "速度 · 坐标" 文本 + 每秒刷新，不是进度条。

## 6. 通知权限（已见）
- App 首次/需要时申请 POST_NOTIFICATIONS（仅 SDK ≥ 33）：`F0/A.java:44-48`（`requestPermissions(new String[]{"android.permission.POST_NOTIFICATIONS"}, 1002)`）。
- 结果回调：requestCode 1002 时 Toast @string/notification_permission_denied "No notification permission, background mock function may be limited" 或 @string/notification_permission_granted "Notification permission granted, background mock function is now available"，并重新跑自检 `P().d()`（`MainActivity.java:4211-4223`）。
- 自检里"Notification permission"一项在 SDK<33 时恒为通过（`F0/b0.java:111`）。

## 7. 前台服务停止（已见）
- 正常停止/失败：`stopForeground(SDK>=24 ? 1 : true)`，即 STOP_FOREGROUND_REMOVE，然后 `stopSelf()`（`MockLocationService.java:372-377, 390-395`）。
- 清理测试 provider、释放 WakeLock 与通知渠道本身不删除（渠道只创建一次）。
